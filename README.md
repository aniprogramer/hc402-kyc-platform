# HC-402: Automated Digital KYC and Onboarding Platform

## Overview

A Progressive Web App (PWA) that performs digital KYC verification including:

- Document OCR extraction
- Face matching
- Fraud detection
- Compliance report generation

## Tech Stack

Frontend: React (PWA)
Backend: FastAPI
Database: SQLite
ML: OCR + Face Recognition
DevOps: Docker + ngrok

## Project Structure

frontend/ - React PWA  
backend/ - FastAPI backend  
ml-service/ - ML processing services  
deployment/ - Docker and scripts  
docs/ - Documentation  
assets/ - Icons and static assets  
uploads/ - Uploaded files
